# OtvetWare

[![CI](https://github.com/Donut1133/OtvetWare/actions/workflows/ci.yml/badge.svg)](https://github.com/Donut1133/OtvetWare/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-informational)](LICENSE)
[![Rust](https://img.shields.io/badge/rust-1.85%2B-orange)](https://www.rust-lang.org/)

Бот для otvet.mail.ru. Нативное окно, много аккаунтов, чистый HTTP — браузер
нужен один раз, чтобы войти.

## Режимы

| | |
|---|---|
| Голоса | плюсы и минусы по профилю целиком или по одной ссылке |
| Ответы | из ленты, по списку ссылок или по диапазону номеров |
| Комменты | ответы тем, кто написал под твоим ответом |
| Вопросы | публикация своих |
| Подписки | подписка и отписка по списку профилей |
| Жалобы | на профиль, на его посты, на ответы или на один пост |

Плюс разовые проверки, которые ничего не меняют: кто голосовал под постом и кто
на кого уже подписан.

## Что есть поверх

**Аккаунты.** Сколько угодно, по очереди или параллельно. Прокси на аккаунт
(HTTP и SOCKS5, в том числе с логином), ротация после сбоев. Лимиты за прогон и
за круг, круги с паузой, пауза и продолжение с той же точки.

**Отпечатки.** У каждого аккаунта своё «железо»: UA с client hints, таймзона,
язык, экран, ядра, память, строки WebGL, шум canvas. Считается по имени
аккаунта, поэтому постоянно, и надевается и на HTTP, и на окно браузера.

**Текст.** Нейросеть (любой OpenAI-совместимый API), готовые фразы или
коверканье. Свои стили и промпты, единый чат с памятью, уникализация без
`#293456` в хвосте. Картинки из вопроса и из реплики собеседника уезжают
нейросети вместе с текстом.

**Отбор.** Слова-приметы: берутся только вопросы, где они встретились. Пропуск
своих вопросов и веток, где уже был другой твой аккаунт.

**Надёжность.** Журналы: дважды на одно и то же не ответит. Проверка, что
отправленное пережило автомодерацию, и другой текст, если сайт отказал. 418 и
429 останавливают аккаунт, сетевые сбои — нет.

**Ответы авансом.** Номера вопросов идут подряд, и сайт принимает ответ на ещё
не заданный. Задаёшь диапазон — бот раскладывает по нему заготовки. Номера
общие на все аккаунты: сколько запустил, во столько раз быстрее.

## Запуск

Скачать `otvetware-windows-x64.zip` из [Releases](../../releases), распаковать,
запустить `otvetware.exe`. Внутри всё нужное, включая браузер.

Дальше: «Добавить аккаунт» → браузер → входишь руками, куки снимутся сами.
Отмечаешь галочками, выбираешь режим, жмёшь «Запустить». Чего не хватает —
кнопка подскажет.

Для режимов с нейросетью нужен ключ, по умолчанию настроен DeepSeek.

## Данные

Всё состояние — в папке `accounts` рядом с `.exe`: аккаунты, отпечатки, стили,
пул картинок, журналы. Переносится копированием этой папки.

> `accounts.json` — живые сессии. У кого файл, у того и аккаунты. Он и журналы
> закрыты в `.gitignore`; не выкладывай их и не прикладывай к issue.

Подробности — в [data/README.md](data/README.md).

## Из исходников

Нужен [Rust](https://rustup.rs/) 1.85+ и браузер: системный Chrome бот не берёт,
тот обновляется сам и разъезжается по версии с отпечатком.

```bash
git clone https://github.com/Donut1133/OtvetWare.git
cd OtvetWare
PLAYWRIGHT_BROWSERS_PATH=./browsers npx patchright@1.60.2 install chromium
cargo run --release -p otvet-gui
```

Два крейта: `otvet-core` — логика, `otvet-gui` — окно на
[egui](https://github.com/emilk/egui). Ядро не знает про интерфейс, гоняется
тестами и зовётся из своих скриптов.

```bash
cargo test --workspace       # 158 тестов, поднимают локальный сервер-заглушку
cargo clippy --all-targets   # чисто
cargo fmt --all
```

Живые проверки на своём аккаунте (`live` реально постит, поэтому просит флаг):

```bash
cargo run -p otvet-core --example check -- "Аккаунт 1"
OTVET_LIVE=yes cargo run -p otvet-core --example live -- ask "Аккаунт 1"
```

## Чего нет

* **TLS-отпечаток (JA3)** — стека ОС, а не Chrome. Порядок заголовков, client
  hints и HTTP/2 воспроизведены, полное совпадение даёт только настоящий браузер.
* **Список шрифтов** — снимается измерением ширины текста, из JS не подделать
  без слома реальных метрик. Лечится только разными хостами.
* **Капча и SMS** — вход всегда руками.
