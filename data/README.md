# Папка данных

Здесь OtvetWare держит всё своё состояние. Программа ищет эту папку так:

1. переменная окружения `OTVET_ROOT`, если задана;
2. папка `accounts` рядом с `.exe` — обычный, портативный вариант;
3. текущая папка, если в ней уже есть `accounts.json`;
4. папка выше по дереву от самого `.exe` с `accounts.json` — так работает
   запуск из `target/release` внутри клона;
5. `./data`, если такая папка есть;
6. новая папка `accounts` рядом с `.exe`.

Если данные лежат прямо рядом с `.exe`,
при запуске они сами переедут в `accounts`: аккаунты, отпечатки, журналы,
`profiles`, `images`, `browsers`. Чужие файлы рядом с программой не трогаются.
Именно переезд, а не копия: две живые копии `accounts.json` — это разъезжающиеся
куки и разлогин на ровном месте.

## Что появится внутри

| Файл | Что в нём | В гите |
|---|---|---|
| `accounts.json` | аккаунты: куки, прокси, карма, userId | **нет** |
| `personas.json` | отпечатки браузера по аккаунтам | **нет** |
| `styles.json` | стили ответов и вопросов для нейросети | нет (есть пример) |
| `gif-pool.json` | пул картинок, которые можно прикладывать к постам | нет |
| `answered_<аккаунт>.ndjson` | на какие вопросы уже отвечали | **нет** |
| `asked_<аккаунт>.ndjson` | какие вопросы уже задавали | **нет** |
| `replied_<аккаунт>.ndjson` | на какие комментарии уже отвечали | **нет** |
| `convo.json` | единый чат режима «Ответы» с памятью | нет |
| `settings.ron` | настройки окна: ссылки, лимиты, промпты, **ключ нейросети** | **нет** |
| `profiles/` | профили браузера по аккаунтам | **нет** |
| `images/` | картинки, которые бот прикладывает к постам | нет |

`accounts.json` содержит живые сессии: тот, у кого есть этот файл, распоряжается
аккаунтами. Он и все журналы закрыты в `.gitignore` — не убирай их оттуда.

## Начать

Скопируй пример стилей и правь под себя:

```bash
cp data/styles.example.json data/styles.json
```

Аккаунты руками создавать не нужно: нажми в программе «Добавить аккаунт»,
залогинься в открывшемся браузере — `accounts.json` появится сам.
Формат файла, если он всё же понадобится, показан в `accounts.example.json`.
